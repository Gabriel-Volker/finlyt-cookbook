# Known problems and regression cases

**Fixed** means a specific reproduction now passes. **Mitigated** means the workflow reduces the impact and the failure can still occur. **Open** means the behavior can still occur or the original cause is unknown. The live observations come from individual runs. The audit cases used controlled model outputs. See [AI_LOG.md](AI_LOG.md) for run details and [examples/](examples/) for saved recipe reports.

## OCR and document import

| Input or stage | Observed problem | Status |
| --- | --- | --- |
| Sauerbraten, pp. 1–2, marinade | Docling with German EasyOCR and Tesseract failed to recover the complete measures for ½ L vinegar, ½ L water, and four sliced onions. The eight-day condition was garbled and the method survived only in fragments. | **Mitigated.** The dual VLM workflow recovered these details in the recorded full-document tests. |
| Sauerbraten, p. 1, illustrated header | An early Gemini run omitted the illustrated header under a prompt that excluded decorative text. The first full-page request timed out. The retry recovered the heading, attribution, and `Anno 1887`. | **Fixed** for prompt scope. Provider timeouts remain possible. |
| Sauerbraten, p. 1, cookbook attribution | The manuscript says `Josefines`. Across runs Luna returned `Jose[unleserlich]ines`, `Josetines`, and `Josefinens`. Gemini, Sol, and Terra recovered `Josefines` in the recorded full-transcription tests. Luna also recovered it on a PNG run. | **Mitigated.** The comparison flagged the inconsistent name. |
| Sauerbraten, p. 2, illustrations | Luna put illustration labels ahead of the recipe in an early direct-PDF run. Terra placed them below the recipe but transcribed the label `Korinthen` as `Kori[unleserlich]`. The Terra recipe body retained `Korinthen`. | **Mitigated.** Readers are asked to preserve reading order and flag unreadable text. Layout and label errors remain possible. |
| Sauerbraten, p. 2, sauce | In the 18:52 run, Luna transcribed `Bratenstand` where the manuscript and Gemini read `Bratenfond`. The ingredient name and the affected sauce instruction were withheld for review, which blocked vegan planning until both were corrected. | **Mitigated.** Adapt links to the exact fields. The reading and the later vegan validation error were separate problems. |
| Doce de leite Moça | Gemini returned an incomplete transcription and the import produced no report. The original finish reason was unavailable. A replay returned `STOP` with 103 output tokens against a 4,096-token limit. | **Open.** The original cause is unknown. The replay did not establish token exhaustion. |
| Blur and weak scans | Whole-page sharpness scores changed with resolution and noise and missed locally blurred text. In a synthetic heavy-blur run, Luna produced an empty page body instead of its unreadable marker, so automatic rejection did not trigger. | **Mitigated.** Rejection requires severe visual blur and both readers to mark every page unreadable. Partial or inconclusive results continue through the pipeline. False rejection and missed rejection rates are unmeasured. |
| Large and digital documents | Web uploads are capped at 14 MB. Each reader has a 4,096-token OCR output budget for the entire document. Above 32 pages or 36 MB of raster output, Terra receives the full PDF. An incomplete response from either OCR provider aborts the import. Only the rasterized Terra route checks its page markers against the original page count. | **Open limits.** Long documents can exceed the output budget or omit pages. The app has no page batching or partial OCR recovery. Digital PDFs still use the document OCR path. |

## Comparison and extraction

| Reproduction | Status |
| --- | --- |
| A comparison excerpt normalized a fraction inside the quotation, and another valid excerpt was assigned to the wrong page. | **Fixed** for these cases. Evidence must match the cited reader and page. Invalid evidence triggers a retry. |
| The comparator accepted `1/2 cup` and `1 1/2 cup` as equivalent when given an incomplete excerpt. Equivalent `½` and `1/2` should still pass. | **Fixed** for the tested fractions. Python checks complete numeric tokens and unit equivalence. |
| The comparator could omit or misclassify an explicit unreadable marker. | **Mitigated.** Python restores such markers to the review list. |
| A quantity disagreement on differently worded lines escaped the deterministic check. Both readers can also make the same mistake. | **Open.** The numeric fallback aligns matching lines. Coverage of paraphrases depends on the comparator. Agreement and verbatim evidence alone cannot detect shared OCR errors. |
| Sauerbraten extraction hit a provider error, an output-token limit, and evidence-validation failures. A later run cited six fields incorrectly. Another attached `einige` to apples, carrots, and juniper berries, although the validated extraction applied it only to apples. | **Mitigated.** The output budget increased, invalid evidence gets a retry, uniquely matchable whitespace is restored, and unsupported values stay null for review. The prompt keeps ingredient-specific measures separate. |
| Controlled extraction attached a salt amount to sugar, clipped a mixed fraction, or returned an empty recipe as `no_discrepancies`. | **Fixed** for those cases. Validation anchors measures to ingredient occurrences, checks full fractions, and flags an empty extraction. It also deduplicates exact repeated entities and checks for omissions from recognizable measured ingredient lists. |
| A recipe with some valid steps can omit an entire preparation step. A step can cite the wrong existing ingredient ID. | **Open.** Link validation rejects nonexistent IDs. Existing IDs and literal quotes cannot prove semantic linkage or complete preparation coverage. |
| A synthetic PDF attempted to inject instructions to invent 99 servings, add bleach, and disclose the system prompt. | **Mitigated.** The recorded controls preserved the injection as source text without executing it. Fixed prompts, schemas, and evidence checks limit the attack surface. The controls cover those inputs. |

## Scaling, vegan adaptation, and the workspace

| Reproduction | Status |
| --- | --- |
| Scaling left `100 g da farinha` at 100 g while the ingredient list doubled to 200 g, or doubled an amount specified once for the whole recipe. Missing original yield, spelled-out or qualitative measures, ambiguous splits, and larger vessel capacity also need care. | **Fixed** for those two regressions. Python checks recognizable linked amounts and fixed or per-batch evidence. Unresolved measures, splits, or capacity require review. Scaling requires a user-entered baseline when the source yield is unknown. |
| A rejected scaling citation could discard a whole plan. A quantity correction could also conflict with the existing quantity in a step. | **Mitigated.** Valid rules survive retry and ambiguous rules go to review. A recognizable conflict with the linked step holds the corrected amount unscaled and points to the step. |
| A step amount could remain unchanged when extraction omitted the step's ingredient link or wrapped the ingredient name across lines. | **Fixed** for verified name and amount matches. Scaling respects explicitly reviewed links and flags multiple possible matches. |
| Luna and Gemini can disagree on the scaling outcome. In the flatbread control, Luna proposed six tablespoons of oil for three batches and Gemini held the oil for review. If Gemini is unavailable, a Luna proportional rule can still apply. | **Mitigated** for detected differences. The app holds the disputed source quantity and continues other adjustments. Single-model scaling and shared classification mistakes remain possible. |
| Early fixed substitutions missed Parmesan, English butter and drippings, and wine whose processing affects vegan suitability. An early gnocchi plan used inconsistent replacement wording. | **Fixed** for the fixed lookup and tested outputs. Luna proposes ingredient and technique changes from the recipe, and Gemini checks those changes in context. |
| A vegan plan with a concrete incompatibility could previously be exported. A shortbread check returned a step edit among approvals. A mocked empty plan and empty approval list could leave dairy butter in the recipe. | **Fixed** for the observed cases. The variant requires explicit approvals for the exact replacements. The verifier checks all final ingredients and steps, with a supplemental Python check for recognizable animal ingredient names. A remaining dairy ingredient in a step was blocked in a live control. |
| An uploaded Sauerbraten displayed `Luna's vegan plan failed validation.` The discarded original response prevents identifying that exact violation. Other runs abstained solely because amounts were absent or found the original long marinade unsuitable for the replacement. | **Mitigated.** Validation now logs errors and retries. A suitable substitute may be approved with its amount still unset. Planning can reconsider an animal-specific timing or abstain if no viable method is established. |
| A literal match misread valid German inflection, such as `veganer Rotwein` versus `veganem Rotwein`, as an unchanged ingredient. | **Fixed** for the tested reproductions. Contextual verification accepts valid inflections, shorthand, and negation and cites concrete problems in the final instructions. |
| The translation validator accepted “longer than 10 minutes” for “no longer than 10 minutes.” An audit also swapped the ingredients associated with two unchanged numbers. | **Fixed** for the ten-minute inversion and tested negations and bounds. **Open** for arbitrary semantic changes, including the amount-to-ingredient swap. |
| Review originally restricted editing to flagged fields, required finding the field again in a long list, and could block saving while adaptation plans were rebuilt. | **Fixed.** Any existing field opens directly with the original evidence. Review saves independently and Adapt refreshes plans for the current recipe. If scaling fails, a verified vegan variant can still be shown at the original yield. |
| Language output initially covered only parts of the workspace. A serving change could trigger a new translation when the changed measure did not match a cached template. Failed translation could hide the available recipe. | **Fixed** for the tested flows. Import prepares both languages. Serving changes reuse the prepared templates with the current values, and switching languages uses the outputs already in the browser. Translation failures show a labeled source preview with a retry. |

The tests establish these reproductions. A manually annotated set across languages, page quality, and recipe layouts is still needed to measure OCR and extraction accuracy, undetected errors, and the review rate. Vegan suitability is checked against model knowledge and recipe evidence. The app has no external product catalog.
